# 週次更新チェックリスト(毎週月曜・担当者用)

スプレッドシート(17社分)の内容をポータルへ反映する作業の手順書。
所要時間の目安: 30〜60分。**順番を守ること。**

## 事前準備

- [ ] 最新バックアップが7日以内にあるか確認(なければ管理者に `npm run backup` を依頼)
- [ ] 17社分のスプシが今週分まで記入されているか確認(未記入の会社はメモしておく)

## 更新作業

- [ ] ポータルに運用者アカウントでログインする
- [ ] 更新タブを開く
- [ ] 会社ごとに、スプシの最新内容を反映する
  - 受講生の追加・削除(退会)
  - ステージ(新規/構築/PR)・評価(S/A/B/F)・進捗%
  - マイルストーン到達チェック
  - 売上
  - MTG記録(実施日・内容・次回アクション・要対応フラグ)
- [ ] 1社終わるごとに**保存**する(まとめて最後に保存しない)
- [ ] 保存ステータスが「保存済み」になることを毎回確認する

## 更新後チェック

- [ ] ダッシュボードで全社の受講生合計が想定通りか確認(前週比±10名以上ズレたら管理者へ報告)
- [ ] 更新ログに今日の更新が全社分残っているか確認
- [ ] 未記入だった会社があれば、その会社名と理由を管理者へ報告

## やってはいけないこと

- 「今月を0で開始」ボタンを押さない(毎月1日に管理者だけが押す)
- スプシ原本の数値を書き換えない(スプシが正本。直すなら各社担当コーチに依頼)
- ログインID/PWを他の人と共有しない
- エラーが出たまま作業を続けない(スクショを撮って管理者へ)

## 困ったら

- 保存に失敗する / 画面がおかしい → 作業を止めて管理者へ連絡
- 誤って消した・上書きした → **自分で直そうとせず**すぐ管理者へ(バックアップから復元できます)
