# 営業資料ドラフト生成

法人向けリスキリング事業「Next Ramp」の営業資料を、最新実績データに基づいて作成する。

## 手順

### 1. 実績を集計する(必須・最初に実行)

```bash
node scripts/company_stats.mjs
```

数字は必ずこの出力から引用する。**記憶や過去の資料の数字を使い回さない**(実績は毎週変わる)。
data.js の `generatedAt` が2週間以上前なら「データが古い可能性があります。従業員の週次更新後に再実行を推奨」とユーザーに伝えたうえで続行する。

### 2. 用途を確認する

ユーザーの依頼から以下を読み取る。不明なら1回だけまとめて確認する:

- 対象: 新規見込み企業への提案 / 既存クライアントへの実績報告 / 汎用会社紹介
- 形式: スライド / 1枚もの / メール添付テキスト
- 強調したい実績: 導入社数・受講生数 / マイルストーン達成率 / 売上実績 / 特定企業の成功事例

### 3. 構成案とドラフトを作る

標準構成(提案資料の場合):

1. 表紙(Next Ramp / キャッチコピー)
2. 課題提起(法人の人材育成・副業支援の課題)
3. サービス概要(TikTok運用リスキリング: 構築→PR の2ステージ、15マイルストーン)
4. 実績ハイライト(集計結果から: 導入社数、受講生数、フォロワー1000達成数、月商達成数)
5. 進捗可視化ポータルの紹介(クライアントは自社進捗をいつでも確認できる)
6. 導入の流れ・料金
7. CTA

**成功事例を載せる場合**は `node scripts/company_stats.mjs --company <id>` で個社データを取得する。
ただし**社名・受講生名は匿名化**(「美容系人材会社A社」など)してから使う。実名掲載はユーザーが明示的に許可した場合のみ。

### 4. ドラフトをユーザーに提示する

Markdownでスライド単位のドラフトを提示し、修正を受け付ける。

### 5. (承認後のみ)Canvaでデザイン化する

ユーザーが「Canvaで作って」と明示したら、ToolSearchで `mcp__Canva__generate-design` 等を読み込み、承認済みドラフトを渡して生成する。

**確認ゲート**: Canvaへの生成・エクスポート・共有は外部サービスへの反映なので、実行前に必ず「Canvaに生成します。よいですか?」と確認する。ブランドカラーは `assets/next-ramp-logo.jpg` のロゴに合わせる。

## 禁止事項

- 受講生の実名・アカウントURLを営業資料に載せない(匿名化必須)
- Supabaseの認証情報・ログインID/PW・ポータルの管理URLを資料に含めない
- 実績数字の推測・盛り(必ず集計スクリプトの出力を根拠にする)
