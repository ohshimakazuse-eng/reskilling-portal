# 月次進捗報告ドラフト生成

ポータルの「進捗報告」欄(良い変化 / 確認したい点 / 今後の支援方針 / 貴社への確認事項)に貼り付けるドラフトを、実績データから会社ごとに生成する。

## 手順

### 1. 対象会社と実績を確認する

```bash
node scripts/company_stats.mjs --format json
```

対象会社の指定がなければ「全社分」を作る。1社ずつ詳細を見る場合:

```bash
node scripts/company_stats.mjs --company <id>
```

### 2. 会社ごとにドラフトを書く

各社について以下の4項目を書く。**ポータルにそのまま貼れる文体**(です・ます調、クライアント向け、1項目2〜4文)にする。

- **良い変化**: マイルストーン新規到達者数、平均進捗、フォロワー達成、売上発生などポジティブな事実。数字を必ず1つ以上入れる。
- **確認したい点**: 要フォロー受講生(評価F・進捗35%未満)の人数と傾向、要対応MTG(連絡が取れない受講生など)。**個人攻撃にならない表現**にする。
- **今後の支援方針**: 確認したい点への具体的な打ち手(個別MTG強化、投稿添削、PR移行支援など)。
- **貴社への確認事項**: クライアント側に依頼したいこと(未返信受講生への社内フォロー、稼働状況の確認など)。なければ「特にございません」。

### 3. クライアント向け表現ルール(重要)

- 受講生の氏名は書いてよい(クライアントは自社受講生を把握している)が、**他社の情報・他社比較は絶対に書かない**
- 「サボっている」「放置」等の否定的表現は使わず「進捗が停滞している」「ご状況の確認が必要」に言い換える
- 売上・進捗の数字は集計スクリプトの出力のみを根拠とする

### 4. 出力形式

会社ごとに以下の形式で出力する(コピペしやすいよう区切る):

```
## 株式会社◯◯ (id)

### 良い変化
...

### 確認したい点
...

### 今後の支援方針
...

### 貴社への確認事項
...
```

### 5. 反映はユーザーが行う

ドラフトをポータルへ保存するのは人間の作業(運用者がポータルの進捗報告フォームに貼り付けて保存)。
このSkillはドラフト生成まで。**ポータルAPIへの自動書き込みは行わない**(本番DB書き込みのため)。
ユーザーが自動反映を求めた場合は、対象会社・内容を提示して明示的な承認を得てから検討する。
